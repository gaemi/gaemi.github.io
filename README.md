# gaemi.github.io

Personal index, writing space, and static app policy pages at [gaemi.github.io](https://gaemi.github.io).

## Commands

```bash
npm run dev                        # 로컬 개발 서버 (private/draft 글 포함 미리보기)
npm run post:new -- <slug>         # 로컬 전용 비공개 글 생성 (src/content/blog/private/)
npm run post:release -- <slug>     # 비공개/초안 글을 정식 공개 상태로 승격
npm run verify                     # 타입 검사 + 프로덕션 빌드 + 유출/경로 무결성 검증
```
