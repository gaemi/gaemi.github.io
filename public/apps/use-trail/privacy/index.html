UseTrail Privacy Policy

Last updated: June 17, 2026

UseTrail helps users review usage history for apps they choose. UseTrail processes usage information locally on the user's device and does not transmit, sell, or share user data.

English 한국어 日本語

English

Overview

UseTrail is an Android app that lets users review usage history for apps they select. UseTrail does not collect, transmit, sell, or share personal data. All usage records are processed and stored locally on the user's device.

Data Processed on Device

UseTrail may store the following data locally on the device:

  • Apps selected by the user for tracking
  • App usage sessions and usage time summaries
  • App settings, such as language and data retention period

Usage Access Permission

UseTrail requires Android Usage Access permission to read app usage history on the device. This permission is used only to show usage records inside the app. The data is not sent to any server.

Data Sharing and Third Parties

UseTrail does not share user data with third parties. UseTrail does not include advertising SDKs, analytics SDKs, or tracking SDKs.

Data Deletion

Users can delete UseTrail data by clearing the app's storage in Android system settings or by uninstalling the app. Users can also change the data retention period in UseTrail settings.

Children

UseTrail is not directed to children and does not knowingly collect data from children.

Contact

For privacy questions, contact the developer through GitHub Issues.

日本語

概要

UseTrail は、ユーザーが選択したアプリの使用履歴を確認するための Android アプリです。UseTrail は個人データを収集、送信、販売、共有しません。 すべての使用記録はユーザーの端末内でのみ処理、保存されます。

端末内で処理されるデータ

UseTrail は以下のデータを端末内に保存する場合があります。

  • ユーザーが追跡対象として選択したアプリ
  • アプリの使用セッションおよび使用時間のサマリー
  • 言語やデータ保持期間などのアプリ設定

Usage Access 権限

UseTrail は端末内のアプリ使用履歴を読み取るために Android の Usage Access 権限を必要とします。この権限はアプリ内で使用記録を表示するためだけに使用 され、データはサーバーへ送信されません。

データ共有および第三者提供

UseTrail はユーザーデータを第三者と共有しません。広告 SDK、分析 SDK、 トラッキング SDK は含まれていません。

データの削除

ユーザーは Android のシステム設定でアプリのストレージを消去するか、 アプリをアンインストールすることで UseTrail のデータを削除できます。 UseTrail の設定でデータ保持期間を変更することもできます。

子ども

UseTrail は子どもを対象としておらず、子どものデータを意図的に収集しません。

お問い合わせ

プライバシーに関するお問い合わせは GitHub Issues からご連絡ください。
